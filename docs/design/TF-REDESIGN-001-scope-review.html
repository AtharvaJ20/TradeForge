Amendment A-01 · Krishna → Arjun · 2026-09-13

Analytics page: widen layout to full-width card grid

The current w-full max-w-xl constraint on AnalyticsPage.tsx produces a ≈512px single-column layout on all screen sizes. This conflicts with the dashboard's full-width treatment and the execution plan's "card grid" goal. Remove the width cap and adopt a two-column auto-fill grid.

D-01 Primary brand color: keep #2563EB or adopt #4F46E5?

Every primary-colored element in the app (CTA buttons, active nav state, focus rings, sidebar active chip) is affected by this decision. Both colors pass WCAG AA (4.7:1 on white). The decision is a brand direction call, not a technical one.

Option AAdopt #4F46E5 (indigo-600) — Usha's recommendation RECOMMENDED

More distinctive than generic SaaS blue. Reads as analytical and deliberate. Differentiates TradeForge from competitors using standard blue. All existing tests will continue to pass since they reference semantic token names, not hex values.

Option BKeep #2563EB (blue-600) — no token change required

Zero implementation risk. All existing UI is already correct. Loses the visual differentiation opportunity but eliminates any color regression risk.

Option CThird option — Atharva names a specific hex

Any indigo/violet in the 4.5:1+ WCAG AA range is acceptable. Provide the hex to Usha for confirmation before Arjun implements.
